# Owwab — project structure

Where things live and where new code goes. The reasons behind the layout are in [ARCHITECTURE.md](ARCHITECTURE.md).

## Repository root

| Path | What it holds |
|---|---|
| `App.tsx` | providers, font loading, splash, error boundary, global overlays (adhan modal, reminder alarm, floating tasbeeh) |
| `index.ts` | forces RTL, registers the app and the TrackPlayer service |
| `src/` | all application code (see below) |
| `native/android/` | hand-written Android code and resources: `java/` (adhan, reminders, battery helpers, `widget/`) and `res/` |
| `plugins/` | Expo config plugins that inject `native/android/` at prebuild: `withOwwabNative.js`, `withFloatingBubble.js` |
| `patches/` | patch-package patches for three libraries, applied on `npm install` |
| `scripts/` | `apk.js` (build and install a release APK), `check-message-verses.js` (data check) |
| `assets/` | app icons, splash, `audio/` (adhan, takbir, salawat), `alarm/` (alarm screen images), `images/`, `patterns/` |
| `landing/` | the website: `index.html`, `media/`, `owwab.apk`, `vercel.json`. Deployed to `owwab.vercel.app` |
| `docs/` | this documentation |
| `videos/` | promo video and carousel sources (marketing, not part of the app) |
| `android/` | generated by `npx expo prebuild`; git-ignored. Never edit it by hand |
| `app.json`, `eas.json` | Expo and EAS configuration |
| `tailwind.config.js`, `global.css`, `nativewind-env.d.ts`, `babel.config.js`, `tsconfig.json` | tooling configuration |
| `CLAUDE.md` | coding rules for agents working in the repo |

## Where new code goes

Adding a feature that needs a side effect (network, storage, a native module):

1. **Entity** — types and static content in `src/domain/entities/`.
2. **Interface** — the contract in `src/domain/services/` (or `src/domain/repositories/` for a data source). Pure logic goes in `src/domain/services/` as plain functions.
3. **Implementation** — a class in `src/data/services/` (or `repositories/`, `notifications/`).
4. **Registration** — add it to `AppDependencies` and `createDependencies()` in `src/data/container.ts`.
5. **Hook** — one job per hook in `src/presentation/hooks/`, reading the dependency with `useDependencies()`.
6. **State** — a slice in `src/presentation/store/slices/`, added to `rootReducer` in `src/presentation/store/index.ts`. Add it to the persist `blacklist` if it is session-only.
7. **Components** — a folder under `src/presentation/components/`, built from the `ui/` primitives.
8. **Screen and route** — a file in `src/presentation/screens/`, the route type in `src/presentation/navigation/types.ts`, and the `Stack.Screen` in `AppNavigation.tsx`.
9. **Native code** — in `native/android/`, wired through `plugins/withOwwabNative.js`, then `npx expo prebuild --platform android --no-install`. If a class or resource is only referenced by name, add a keep rule.
10. **A new reminder kind** — a new scheduler class passed to `ExpoNotificationCenter` in the container.
11. **Docs** — a file in `docs/features/` using the template in [features/README.md](features/README.md).

Check with `npx tsc --noEmit -p .` before calling a change done.

## Conventions

**Imports**
- Presentation does not import `src/data/**` (except `DependencyProvider` importing the container), `expo-location`, `expo-notifications`, AsyncStorage or native modules.
- No UI in the data layer: no `Alert`, `Linking`, navigation or Arabic UI strings. Return data and let presentation show it.

**UI**
- Colours, spacing, radius, type and icon sizes come from `src/shared/theme/tokens.ts`; the accent comes from `useAccent()`. No literal hex colours.
- Icons are `lucide-react-native` only, with `icon.stroke`. One accent colour; no gradients except the adhan screen.
- Strings are Egyptian Arabic; digits go through `toAr` in `src/shared/utils/format.ts`.

**Forced RTL on Android**
- A plain `flexDirection: 'row'` already runs right to left. Write children in reading order; never use `row-reverse` to get "Arabic order".
- `textAlign: 'right'` on `<Text>` renders on the left: leave it unset.
- `alignItems` / `alignSelf: 'flex-end'` means the left side; use `flex-start` for the right.
- `left:` and `right:` are swapped; overlays positioned by coordinates need `direction: 'ltr'` on the container.
- Check layout on the emulator or a phone. A web preview does not reproduce the flipping.

**Nested `<Text>` on Android**
- `color: 'transparent'` and `opacity` are ignored on nested Text: use the background colour or an rgba colour.
- No `columnGap` / `rowGap` in wrapped RTL rows: use per-item margins.
- Put the trailing space inside each word's pressable Text, so taps between words land.

**Native**
- The app is bridgeless: get the React context from `(application as ReactApplication).reactHost?.currentReactContext`.
- Edit native code in `native/android/`, never only in `android/`.
