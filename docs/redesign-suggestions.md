# أوّاب — اقتراحات إعادة التصميم

هذه الوثيقة تلخّص ما وجدته في التطبيق الحالي، وما أقترحه لإعادة التصميم، مرتّبًا حسب الأثر على المستخدم.

## 1. ما يعمل جيدًا الآن (نحافظ عليه)

- الهوية اللونية: خلفية داكنة `#0c0805` مع ذهبي `#B8860B / #fcd34d` وخطوط Tajawal/Amiri. هوية واضحة ومميزة، لا نغيّرها.
- بنية الكود: فصل `screens / components / store` واضح، وكل شاشة لها ملف ستايل خاص.
- وجود "رحلة القلب"، "ورد يومي"، والإحصائيات: ميزات تميّز التطبيق عن المنافسين.

## 2. مشاكل تصميم ملاحظة

| المشكلة | أين | الأثر |
|---|---|---|
| شريط التبويب عائم بارتفاع 70 ومسافة 25 من الأسفل، لكن الشاشات لا تترك مساحة له | `AppNavigation.tsx` | آخر عنصر في كل شاشة يختفي خلف الشريط |
| 13 شاشة لكن 4 تبويبات فقط، والباقي عبر `HomeGrid` | Home | "الإعدادات" و"الإحصائيات" مخفيتان في الهيدر، صعب الوصول |
| كل بطاقة لها حدود + ظل + تدرّج | Home, Settings | ضجيج بصري، لا يوجد تسلسل هرمي: كل شيء مهم بنفس الدرجة |
| ألوان مكتوبة مباشرة (`'#1a140f'`) في 40+ ملف بدل `THEME` | كل الـ Styles | أي تغيير في الهوية يحتاج تعديل يدوي في كل مكان |
| العدّاد في المسبحة كان دائرة عادية | Tasbeeh | لا يوحي بالمسبحة الحقيقية (تم استبداله بـ SVG واقعي) |
| لا توجد حالات فارغة/تحميل/خطأ | Prayer, Quran, Stats | إن فشل الـ API تبقى الشاشة فارغة بلا تفسير |
| `Alert.alert` للصلاحيات (6 تنبيهات متتابعة) | Settings/Azan | تجربة مربكة؛ المستخدم يلغي ولا يعرف ما ينقصه |
| النصوص: "الهدف: ٣٣" بجانب أيقونة Target من lucide | Tasbeeh | خلط بين أيقونات غربية ولغة عربية |

## 3. المقترح: نظام تصميم موحّد

### 3.1 Tokens (في `shared/theme/constants.ts`)

```ts
colors: {
  bg: '#0c0805', surface: '#14100b', surfaceRaised: '#1a140f', border: '#2b1f15',
  gold: '#d4af37', goldSoft: '#fcd34d', goldDeep: '#B8860B',
  text: '#f5f0e6', textMuted: '#9c9284', textFaint: '#5c554b',
  success: '#22c55e', danger: '#ef4444',
}
radius: { sm: 10, md: 16, lg: 22, pill: 999 }
spacing: 4-pt scale (4, 8, 12, 16, 24, 32)
type: { display: Amiri 34, h1: Tajawal 24/Bold, h2: 18/Bold, body: 15, caption: 12.5 }
```

قاعدة: ظل واحد فقط للعناصر "المرفوعة" (البطاقة الأساسية في كل شاشة). كل ما سواها بدون ظل وبحدود 1px.

### 3.2 الصفحة الرئيسية

- **بطاقة واحدة بطلة**: "الصلاة القادمة" بعدّاد تنازلي كبير (الخط Amiri) وخلفية المسجد، وهي الوحيدة التي تحمل تدرّجًا وظلًا.
- **صف تقدّم اليوم**: ثلاث دوائر صغيرة (العبادات، الورد، الأذكار) بدل ثلاث بطاقات.
- **شبكة الأدوات** بأيقونات أحادية اللون (ذهبي على سطح داكن) وبدون حدود؛ أعمدة 4 بدل 3.
- الآية اليومية تنتقل إلى أسفل الصفحة كـ "فاصل هادئ" بخط Amiri فقط.

### 3.3 التنقل

- خمسة تبويبات: الرئيسية، الصلاة، القرآن، المسبحة، الأذكار. الإعدادات والإحصائيات من الهيدر (كما هو) + سحب من الرئيسية.
- إضافة `paddingBottom: 110` كقيمة موحّدة (`THEME.tabBarInset`) لكل `ScrollView`.

### 3.4 المسبحة (منفّذ في هذا التعديل)

- SVG واقعي: 33 خرزة + فاصلان + "إمام" + شرابة. كل ضغطة تدير الحلقة خرزة واحدة مع توهّج تحت الإبهام.
- الألوان تُشتق من لون الفقاعة العائمة المختار (خشب، عنبر، أونكس...).
- اقتراح لاحق: نفس الرسم كصورة Vector Drawable للفقاعة العائمة على أندرويد (الفقاعة الآن PNG من المكتبة).

### 3.5 الإعدادات / الأذان

- استبدال سلسلة `Alert` بشاشة "جاهزية الأذان" بقائمة فحص: ✅ الإشعارات، ✅ المنبهات الدقيقة، ✅ ملء الشاشة (أندرويد 14+)، ✅ البطارية، ✅ إعدادات الشركة المصنّعة. كل بند بزر "إصلاح".
- زر "تجربة الأذان بعد 30 ثانية" يبقى، ويعرض الوقت المتبقي.

### 3.6 الحالات

- كل شاشة تعتمد على الشبكة تعرض: Skeleton عند التحميل، ورسالة + زر "إعادة المحاولة" عند الفشل، وآخر بيانات محفوظة عند انقطاع الإنترنت.

## 4. ترتيب التنفيذ المقترح

1. Tokens + إزالة الألوان المكتوبة مباشرة (يوم عمل، آلي بالبحث والاستبدال).
2. الرئيسية + التبويبات + مسافة الشريط السفلي.
3. شاشة جاهزية الأذان.
4. الحالات الفارغة/الفاشلة.
5. ويدجت أندرويد: تصميم 4×1 و 2×2 بخلفية زجاجية وبدون صورة المسجد المكرّرة.

## 5. الاتجاه البصري "المودرن" المقترح (رأيي)

التطبيق الحالي "فاخر وثقيل": ذهبي على بني، حدود مزدوجة، ظلال كثيرة، وكل عنصر له إطار. المودرن هنا لا يعني تغيير الهوية بل **تخفيفها**:

1. **سطح واحد داكن بدل البطاقات المتراكبة**: خلفية `#0c0805` ثم بطاقات بلا حدود بلون `#14100b`، والفصل بينها بالمسافة (16) لا بالإطارات. الحدود الذهبية تبقى لعنصر واحد فقط في كل شاشة (العنصر النشط).
2. **ذهب واحد**: `#d4af37` للنصوص والأيقونات المهمة فقط. التدرجات الذهبية تُستبدل بلون مسطح. العناوين بـ Amiri، كل ما عداها Tajawal.
3. **أرقام كبيرة، نصوص قليلة**: العدّاد التنازلي للصلاة، نسبة الختمة، عدد التسبيح: كلها بحجم 40+ وخفيفة، مع شرح من كلمتين تحتها بلون خافت `#9c9284`.
4. **حركة هادئة بمعنى**: نبض القلب، دوران المسبحة، امتلاء الدم. لا حركات زخرفية أخرى.
5. **زوايا 20 للبطاقات، 999 للأزرار الصغيرة، 12 للحقول**. لا شيء بينها.
6. **الأيقونات**: Lucide بخط 1.75 فقط (إزالة FontAwesome وMaterial المختلطة).
7. **الزجاج** (blur) في مكانين فقط: شريط التبويب السفلي وشاشة الأذان.

### 5.1 ما نُفّذ كنموذج لهذا الاتجاه

- **رحلة القلب**: قلب إنسان تشريحي بـ SVG (بطينان، أذينان، قوس الأبهر وفروعه الثلاثة، الجذع الرئوي، الوريد الأجوف، الشرايين التاجية). الدم يرتفع من القمة بنسبة الختمة، و30 عقدة على الشرايين التاجية تضيء ذهبياً عند اكتمال كل جزء. النسبة واسم العدّ داخل البطين الأيسر. أُزيلت اللوحة الكريمية و114 خلية بأسماء غير مقروءة.
- **المسبحة**: 33 خرزة SVG بتدرج وظل، شرابة، وتوهّج تحت الإبهام.

### 5.2 الخطوة التالية المقترحة بنفس الأسلوب

الصفحة الرئيسية: بطاقة "الصلاة القادمة" كعنصر بطل وحيد بخلفية المسجد المعتمة وعدّاد كبير، وصف دوائر تقدّم صغيرة (عبادات، ورد، أذكار) بدل ثلاث بطاقات، وشبكة أدوات 4 أعمدة بأيقونات أحادية.
