# Owwab (أوّاب) — rules for agents

React Native 0.81 + Expo 54, Android first, Arabic UI with forced RTL, New Architecture (bridgeless).
Check every change with `npx tsc --noEmit -p .` before calling it done.

## Architecture (SOLID)

Three layers. Dependencies point inward only: `presentation → domain ← data`.

| Layer | Folder | Holds | May import |
|---|---|---|---|
| domain | `src/domain/` | entities, pure logic (`services/geo.ts`, recitation matching), and the **interfaces** for anything with side effects | `domain`, `shared` only — no React, React Native, expo, fetch or storage |
| data | `src/data/` | the classes that implement those interfaces (APIs, AsyncStorage, expo, native modules) | `domain`, `shared` |
| presentation | `src/presentation/` | screens, components, hooks, Redux store | `domain`, `shared`, and `data/container` through `useDependencies()` only |

- **New service = interface first.** Declare the contract in `src/domain/services/` (or `domain/repositories/` for data sources), implement it as a class in `src/data/`, and register it in `src/data/container.ts`. `LocationProvider` / `ExpoLocationProvider` and `PrayerTimesSource` / `AladhanPrayerTimes` are the pattern to copy.
- **Presentation never imports `src/data/**` directly** (except `DependencyProvider`'s import of the container) and never imports `expo-location`, `expo-notifications`, AsyncStorage or native modules. Take dependencies from `useDependencies()`, so tests can pass fakes to `DependencyProvider`.
- **No UI in the data layer:** no `Alert`, `Linking`, `ToastAndroid`, navigation or Arabic UI strings in `src/data/`. Return data (a URL, a result, an error), and let presentation show it.
- **One job per unit.** A hook does one thing (fetch X, watch Y); a screen composes hooks. If a hook needs a second responsibility, split it (as `useHeading` was split out of `useLocation`). Logic that is not React belongs in `domain`, not in a hook.
- **Extend, don't edit.** New reminder kinds are a new scheduler passed to `ExpoNotificationCenter` in the container, not a branch inside the center. Apply the same idea elsewhere: add an implementation rather than a special case.
- **Reuse before writing.** Look in `src/domain/services/`, `src/shared/utils/format.ts` and `src/presentation/components/ui/` before adding a helper (e.g. bearings come from `geo.ts`, Arabic digits from `toAr`).

Older code still breaks these rules (tasmee, reminders, `ayahSearch` and `hadithLibrary` are imported straight from `src/data`; see issue #24). Don't copy that; when you touch such code, move it behind the container if the change is small, or say it's left as is.

## UI

- Use `src/shared/theme/tokens.ts` (colors, radius, space, type, icon) and `useAccent()`; no literal hex colours. Build from the primitives in `src/presentation/components/ui/`.
- Icons: `lucide-react-native` only, stroke `icon.stroke`. One accent colour; no gradients except `AzanVideoModal`.
- Strings in Egyptian Arabic, digits through `toAr`.

### Forced RTL (Android)

- A plain `flexDirection: 'row'` already runs right-to-left: write children in reading order. Never use `row-reverse` for "Arabic order".
- `textAlign: 'right'` on `<Text>` renders on the LEFT — leave it unset. (TextInput is fine.)
- `alignItems/alignSelf: 'flex-end'` means LEFT; use `flex-start` for the right side.
- `left:`/`right:` are swapped; coordinate overlays need `direction: 'ltr'` on the container.
- Verify layout on the emulator: the web preview does not reproduce RTL flipping.

### Android nested `<Text>`

- `color: 'transparent'` and `opacity` are ignored on nested Text: use the background colour or an rgba colour.
- No `columnGap`/`rowGap` in wrapped RTL rows; use per-item margins.
- Put the trailing space inside each word's pressable Text so taps between words land.

## Native Android

- `android/` is gitignored and regenerated by prebuild. Hand-written native code lives in `native/android/` and is injected by `plugins/withOwwabNative.js`; edit it there, never only in `android/`.
- The app is bridgeless: `reactInstanceManager.currentReactContext` is always null. Use `(application as ReactApplication).reactHost?.currentReactContext`.
